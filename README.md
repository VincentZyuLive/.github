# VincentZyuLive

VincentZyu 的直播相关工具集合。这里的项目以个人直播环境为主要使用场景，实验性项目较多，
按需持续迭代，也欢迎体验、反馈 Issue 和提交 PR。

[![Bilibili](https://img.shields.io/badge/Bilibili-5861873-00A1D6?style=for-the-badge&logo=bilibili&logoColor=white)](https://live.bilibili.com/5861873)

## 项目

- [Bili Live Danmaku](https://github.com/VincentZyuLive/bili-live-danmaku)：B站透明弹幕 OBS 浮层
- [OBS Stage](https://github.com/VincentZyuLive/VincentZyu233-OBS-stage)：水色雾蓝 OBS 舞台 WebUI
- [go-musicfox fork](https://github.com/VincentZyuLive/go-musicfox-vincentzyu-fork)：VincentZyu 的 fork 版本，并增加 SPlayer-Next 兼容 HTTP/WS API

完整介绍见 [组织主页](https://github.com/VincentZyuLive)。
